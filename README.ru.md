# @goodandready-private/dsh-approval-gate

Host-only шлюз: до запуска тела инструмента блокирует опасные вызовы bash и запись в секретные файлы. Дальше действует уже существующее слово подтверждения `делай`.

Таблица покрытия, ограничения и конфигурация — в [README.md](README.md).

Установка (приватный пакет GitHub Packages):

```sh
dsh plugin --profile web add @goodandready-private/dsh-approval-gate
```
